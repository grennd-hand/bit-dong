# BIT东｜视频扩展使用入口

原版 `bitdong-illustrations` 的9个原始文本文件和25张原始图片保持升级前的字节不变。视频扩展作为独立、自包含的 `skills/bitdong-video/` 存在，不替换原插画 Skill。

## 现在能做什么

使用真实原图准备分镜和参考包；分别生成首帧提示与运动提示；登记真正生成的首帧；验证原图完整性、拒绝旧错误候选及其登记的派生链；导出中英文视频输入草案；在真实批准及当前平台资料齐全后导出正式输入包。没有内置视频厂商调用，没有跨平台实拍通过的声明。

## 安装

从完整仓库直接选独立目录，避免安装器把它当成原插画技能的覆盖升级：

```bash
npx skills add https://github.com/grennd-hand/bit-dong/tree/main/skills/bitdong-video --skill bitdong-video -g -a codex -y
```

原插画技能仍叫 `bitdong-illustrations`，需要更新其已安装副本时用原来的安装入口。仓库合并不会自动更新你电脑上已有的安装副本。安装命令的形式依据 skills CLI 官方文档；本次服务器验收不等于已操作你的电脑。

## 直接使用

在助手里输入：

```text
使用 $bitdong-video，严格沿用原来的Bit东形象，不重新设计人物。
为我准备一条10秒问候视频：先给出原始参考、两镜头分镜、每镜头首帧和运动提示。
有生成工具时先做第一镜的首帧并与原版核对，没有真实视频结果不要写已验收。
```

命令行准备包、真实帧登记和导出用法见独立 Skill 的 `SKILL.md`。根目录同样提供这些脚本与两镜头示例。

## 防止再次改坏

原图锁定覆盖原版34个文件。拒绝清单按ID、套装、路径、SHA256及登记的父参考链检查，`--allow-draft`也不例外；重新编码、重新绘制的视觉相似性仍需人工比对，哈希不是人脸识别。旧错误图只为历史追溯保留，不属于有效视频参考。

源照片、角色卡和鞋板是图像制作参考。它们是拼板/来源图，不会被改名成已经批准的视频首帧。示例提供明确的待登记ID，不伪造图像存在或用户批准。

## 许可与外部服务

角色与原始图片的授权范围没有扩大；仓库仍不新增开源许可证。实际图像/视频模型需要相应账户、权限和额度；是否支持某种输入模式要在执行时核验。独立 Skill 的复制只为了自包含安装，不产生新的角色版本。
