# Bit东角色规范

## 版本与状态

- 继承设计基线：`design_version = 1.0-inherited`。
- 新转面候选集：`set_id = bitdong-v2-candidate-20261030`。
- 当前 `approved_master_set = null`；仓库尚无已批准的视频角色母版集。
- 所有新生成图均为 `candidate`。允许用于分镜、首帧试做与外观评审；不得称为最终定稿或已完成跨模型视频验证。
- 新母版通过外观审查后再记录批准者、日期、版本与文件哈希。图像检查通过不自动等于用户批准。

镜头首帧负责本镜头的构图、姿态与光线，不能覆盖所选角色版本的身份约束。已有批准母版时，旧照片或细节来源中的冲突只能进入版本修订，不能静默覆盖母版。
根据镜头只加载必要的参考，不强制每次同时上传自拍、角色拼图、鞋板、表情表。单图图生视频使用已检查的完整场景首帧；不要把多角色拼图直接当成首帧。

## 固定身份与服装

- 保持成年中国男性的偏长、利落椭圆脸，短刺黑发和较短两侧；不漂成通用动漫脸或未成年。
- 保持深色粗框矩形眼镜及镜腿连接关系；自然成人眼睛。表情改变眼睑与视线，不放大眼球或改圆镜框。
- 沿用成熟成人比例，目标约7–7.5头身；以本次选定图的实际身体轮廓统一各视角，不逐张重新设计身高、肩宽和腿长。
- 保持素色珊瑚粉圆领卫衣：无帽、无抽绳、罗纹领口/袖口/下摆。英文使用 `crewneck sweatshirt`，不用 `hoodie`。
- 保持银色链条、炭黑色宽松长裤和原定制黑色高帮鞋。中性光下对照同一母版颜色，不凭空设定未经采样的“官方色号”。
- 真人照片胸前有纹章，当前动漫设计为素色；默认不把照片纹章加回动画服装。
- 候选集沿用角色**左手腕**的深色圆表；正面在画面右侧、背面在画面左侧。允许因袖口、远侧手臂或身体遮挡而不可见，不得换腕、复制或无故消失。
- 保持利落2D动漫墨线和克制赛璐璐明暗。改变场景与照明不等于改变角色的渲染风格。

## 定制鞋与左右关系

- 锁定黑色皮面/鞋带、高帮轮廓、米白中底、黑色外底、蓝色侧边装饰和红粉色鞋头图案。
- 近景再核对紫色小图案、黄橙色后跟线稿与浅蓝手写 `BIT / DONG`；远景允许细节不可辨，不能换成低帮、白鞋或普通黑鞋。
- 暂用 `shoe_A_BIT`、`shoe_B_DONG` 区分这双鞋；文字与角色左右脚的对应尚未核实，不得编造。
- 不把画面左右等同于角色左右。需要精确映射时，依据原始鞋照和实际鞋型逐项确认并记录。
- 不用水平镜像冒充另一侧视图；鞋子不对称图案、字母和手表必须保持物理一致。
- **鞋款区别已按来源线索配对**：BIT 对应红色 D 形图形及圆头图案，DONG 对应红色 Z 形图形及带身体的人物图案。此为两只鞋的图案识别，不等于已确认角色左/右脚；细微字样仍须参照原鞋实拍逐一核实。
- DONG 鞋外侧的蓝色轮廓及内部小花纹需要真正的对侧视角核验；近景无法还原时保留为待修缺陷，不以镜像、模糊或单纯色块替代。鞋头红色小字、后跟细线的动漫化简化也须单独记录。
- 进一步的制作、校验与局限见 [鞋子识别专项规范](shoe-identity.md)。
- 原始鞋板也是设计来源，不意味着新生成鞋图已经逐字准确；鞋帮字形错误必须单独记录。

## 隔离历史与范围

将 `bitdong-character-sheet-pre-custom-shoes.png`（白灰低帮鞋）及 `assets/examples/` 视为 `archived`，保留历史但从自动角色参考选择中排除。
