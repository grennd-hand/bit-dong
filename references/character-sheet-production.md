# 角色补角度｜只从原版出发

原版角色规范、照片、动漫角色卡、情绪/身体语言表和鞋子来源是唯一原始设计依据。先看原图，再生成场景首帧；不要重新设计一套人物，也不要以新候选立绘反过来覆盖原版。

被用户否定的 video-v2-candidates 和后续三分之四新图不能继续用于派生。原始拼板可以作为图像生成参考，不能直接注册为单角色场景首帧；裁切/插值也不能冒充新原生高清细节。

新生成的场景帧先与原图对照，再记录真实文件、实际提示和真正用过的参考。使用 `register_frame.py` 登记为candidate。可将通过视觉检查的同版场景帧用于下一镜头，但不得虚构用户批准或静默改变身份。

完整操作见 `../VIDEO_EXTENSION.md` 和 `../skills/bitdong-video/SKILL.md`。
