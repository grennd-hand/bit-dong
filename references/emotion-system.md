# Bit东情绪系统

## 核心规则

把情绪当作叙事信息，不当作装饰。每次构图先写清：`情绪类型 + 强度 + 触发原因 + 面部动作 + 身体动作`。除非画面表达观察、停顿或校准，否则不要默认中性脸。

工作、操作、风险、卡点、顿悟和结果场景，加载 `assets/character-reference/bitdong-expression-sheet-v1.png`。表情表按从左到右、从上到下排列：

1. 冷静中性 / 高度专注 / 怀疑审视 / 真正困惑
2. 克制焦虑 / 受阻挫败 / 顿悟惊讶 / 压住恼火
3. 干涩苦笑 / 明显释然 / 充能兴奋 / 安静坚定

好奇、倾听、疲惫、无奈、失望、尴尬、同理、期待与自信等场景，改为加载 `assets/character-reference/bitdong-social-expression-sheet-v1.png`。细腻与社交情绪表按从左到右、从上到下排列：

1. 好奇探询 / 谨慎期待 / 温暖同理 / 平静倾听
2. 明显疲惫 / 无奈接受 / 克制失望 / 安静悲伤
3. 尴尬局促 / 内疚致歉 / 满足自信 / 克制自豪

除非画面明确混合两组情绪，不要同时加载两张表。表情表只定义情绪范围；身份与脸型仍以原照片为准，动漫造型以角色卡为准。

## 强度

- `0 校准`：近乎中性，只用于观察、停顿、背景状态。
- `1 克制`：眉眼和嘴角可读，身体变化轻微；适合多数解释图。
- `2 明确`：缩略图可读，头部、肩颈和手势同步；适合转折、冲突和结果。
- `3 峰值`：只用于真正的失败、突破或强烈警报；仍保持成年比例，不做表情包、尖叫脸或萌系夸张。

默认使用 1-2 级。不要为了“成熟”把所有情绪压回 0 级。

## 情绪映射

| 情绪 | 适合的叙事节点 | 面部与身体线索 |
| --- | --- | --- |
| 专注 | 搭建、操作、修复、判断 | 眉心轻收，视线锁定目标，身体前倾，手部精确 |
| 怀疑 | 质疑、风险、反常识 | 单侧眉抬高，眼神侧移，嘴唇轻抿，头略偏 |
| 困惑 | 信息冲突、规则不清 | 双眉内抬，视线来回，嘴微张，摸头或停手 |
| 焦虑 | 过载、失控、截止压力 | 眉间紧，眼睑张力、下颌收紧，肩颈上提，手靠近口鼻 |
| 挫败 | 卡住、失败、反复返工 | 眉压低，闭眼或目光下沉，嘴角压住，扶额或塌肩 |
| 顿悟 | 认知转折、找到关键 | 眼睛瞬间打开，嘴微张，头抬起，手指或身体突然定住 |
| 恼火 | 坏流程、重复错误、荒谬规则 | 眉压低、侧视、咬肌略紧，动作变硬但不暴怒 |
| 苦笑 | 自嘲、冷幽默、荒诞现实 | 单侧嘴角上扬，眼神清醒，头略偏，肩膀轻松 |
| 释然 | 闭环、问题解决、负担卸下 | 眉眼松开，呼气感，轻笑，肩膀下降、身体打开 |
| 兴奋 | 新机会、启动、阶段成功 | 眉眼上扬、真笑，身体向前，握拳或抬手；避免少年式狂喜 |
| 坚定 | 决策、执行、守住原则 | 眉眼稳定、下颌明确、视线直指目标，重心扎实 |
| 中性 | 观察、停顿、校准 | 面部放松但眼神仍有注意力；不得连续滥用 |

## 细腻与社交情绪映射

| 情绪 | 适合的叙事节点 | 面部与身体线索 |
| --- | --- | --- |
| 好奇 | 探索、追问、第一次接近 | 单眉轻抬，眼神贴近目标，头与重心前探，一手试探伸出 |
| 谨慎期待 | 等待结果、准备开启、尚未确认 | 眼神略抬，克制半笑，胸腔微提，双手轻收而不僵 |
| 同理关切 | 回应痛点、理解用户、支持他人 | 眉眼柔和，稳定注视，身体朝向对方，低位开放掌心 |
| 平静倾听 | 访谈、接收反馈、陪伴 | 小幅点头，嘴部放松，肩胸开放，双手安静，保持尊重距离 |
| 疲惫 | 长期过载、重复劳动、能量见底 | 眼睑沉重，头下降，脊柱变圆，重心下坠，手扶额或垂落 |
| 无奈 | 无法改变的限制、荒谬现实 | 呼气感，嘴角压住，肩膀下落，低位摊手，重心近乎放弃 |
| 失望 | 结果低于预期、承诺落空 | 视线下沉，眉间轻夹，胸腔收拢，手失去能量 |
| 安静悲伤 | 失去、孤独、停顿反思 | 眼神远离，嘴角自然下落，身体收拢；不用眼泪或戏剧化哭相 |
| 尴尬 | 社交失误、冷场、被点破 | 视线避开，局促半笑，半侧身或后撤，一手碰颈部或眼镜 |
| 内疚致歉 | 承认错误、请求修复 | 眉内侧上抬，目光犹豫但不逃避，双手合拢或单掌示意 |
| 满足自信 | 验证有效、掌握方法、稳定输出 | 目光平稳，轻微自信笑，脊柱直立，肩胸打开，重心扎实 |
| 克制自豪 | 阶段成果、身份确认、安静认可 | 下颌微抬，眼神从容，姿态开放但不叉腰炫耀 |

## 身体语言系统

脸部不是唯一信号。人物为中景、全身、分镜或情绪主要靠姿态表达时，加载 `assets/character-reference/bitdong-body-language-sheet-v1.png`。十二格顺序为：

1. 精确专注 / 怀疑评估 / 好奇靠近 / 专注倾听
2. 疲惫塌落 / 无奈摊手 / 失望收拢 / 焦虑自缩
3. 尴尬后撤 / 同理支持 / 扎实自信 / 坚定迈步

每个姿态至少明确以下六项中的四项：

- 重心：向前、向后、下坠、扎实或移动中。
- 脊柱：直立、前倾、后仰、圆背或扭转。
- 肩胸：打开、收拢、抬高、不对称或下落。
- 站距与步态：窄站、宽站、后撤、试探步或坚定跨步。
- 手势：高度、离躯干距离、掌心方向、抓握或松弛程度。
- 空间距离：靠近目标、保持倾听距离、退避或守住边界。

遮住脸后仍应大致读出情绪；遮住身体后脸也应表达同一方向。若两者冲突，先修正重心和肩胸，再修正手势，不要只换嘴角。

## 连续性

- 单张图：让情绪与核心动作表达同一件事。脸在焦虑，身体不能像轻松摆拍。
- 前后对比：必须有清楚的情绪差，例如焦虑 -> 释然、困惑 -> 顿悟、挫败 -> 坚定。
- 小漫画：先写情绪弧线，再写动作；2-4 格不能只是同一张脸换姿势。
- 多图文章：相邻图片避免重复同一情绪。除非正文刻意维持压力，否则连续三张不得都用中性或专注。
- 远景小人：脸难以读取时，以轮廓、头部角度、肩颈、重心、步态、手势和空间距离承担情绪。

## 约束

- 保持同一个成年中国男性身份、偏长脸型、自然成人眼睛和同款眼镜。
- 允许眉毛、眼睑、视线、嘴型、脸颊与下颌随情绪变化；不要只改嘴角。
- 允许眼镜因动作轻微倾斜，但不得变成另一副眼镜或遮掉身份。
- 禁止 Q 版、萌系、颜艺、巨大眼泪、尖叫嘴、通红整脸、儿童式撒娇或网络表情包。
- “冷幽默”是一种可读的苦笑、无奈或审视，不等于永久扑克脸。
