# Bit东表情与动作

## 固定角色，变化演出

每个镜头先写 `情绪 + 强度 + 触发原因 + 面部动作 + 身体动作 + 起止状态`。
角色外形遵循 [角色规范](bitdong-character.md) 的同版本母版/候选集。表情表仅是演出参考，不能覆盖脸型、年龄、眼球尺寸、眼镜框形或服装。
允许眼睑、眉毛、视线、嘴型与下颌动作变化；保持五官附着与骨骼轮廓连续。眨眼闭合时不残留瞳孔，高光随眼睑遮挡与光线合理变化。
不要为了表达惊讶而照抄工作表中偏圆大的眼睛和镜框。使用眉毛上扬、眼睑适度张开、呼吸停顿与身体停顿表达。
母版、中性站姿、口播停顿、倾听与镜头衔接允许中性表情；不强制相邻视频镜头改变情绪。

## 强度与动作幅度

| 强度 | 使用范围 | 表演幅度 |
| --- | --- | --- |
| 0 中性 | 母版、停顿、倾听、口播恢复态 | 自然呼吸、轻微眼动，身体放松且稳定 |
| 1 克制 | 日常解释、思考、交流 | 小幅眉眼/嘴角变化，低位手势 |
| 2 明确 | 转折、冲突、结果 | 头部、肩颈、重心与手势协同，保持成人比例 |
| 3 峰值 | 剧情确需的突破或强烈反应 | 短促且可恢复，不用夸大眼球或变形镜框代替表演 |

默认依照叙事选择0–2级，不为了“丰富”提高强度。先完成一个主动作，再加入必要的次级动作。

## 演出提示

| 情绪 | 面部线索 | 身体线索 |
| --- | --- | --- |
| 专注 | 眉心轻收，视线锁定目标 | 轻微前倾，手部操作精确 |
| 怀疑 | 一侧眉轻抬，嘴唇轻抿 | 头略偏，动作停顿 |
| 困惑 | 内眉上抬，嘴微张 | 停手或小幅摊手 |
| 焦虑 | 眉间紧，下颌收紧 | 肩颈上提，呼吸略短 |
| 挫败 | 目光下沉或短暂闭眼 | 呼气、塌肩；扶额时核对手脸接触 |
| 顿悟 | 眉抬、嘴微张，眼球尺寸不变 | 头抬起、主动作短暂停住 |
| 恼火 | 眉压低、嘴角压住 | 动作略硬，保持控制 |
| 苦笑/无奈 | 单侧嘴角轻扬或轻叹 | 肩膀落下，低位摊手 |
| 释然 | 眉眼放松、轻笑 | 呼气、肩膀下降、身体打开 |
| 兴奋 | 自然笑容、目光明亮 | 重心前移，短促抬手，避免持续挥舞 |
| 坚定/自信 | 目光稳定、轻微自信笑 | 重心扎实，脊柱自然直立 |
| 好奇/期待 | 单眉轻抬、克制半笑 | 小幅前探，手势留出等待空间 |
| 同理/倾听 | 眉眼柔和、嘴部放松 | 面向对方，小幅点头，开放掌心 |
| 疲惫/失望 | 眼睑沉重、目光下降 | 重心下沉、动作减少 |
| 悲伤 | 视线远离、嘴角自然下降 | 身体略收拢，幅度依剧情决定 |
| 尴尬/致歉 | 短暂避开视线、局促半笑 | 半侧身、轻微后撤或低位示意 |
| 中性 | 面部放松，保留注意力 | 呼吸自然，关节不僵硬 |

## 身体与连续性

- 按镜头明确重心、脊柱、肩胸、站距/步态、手势、空间距离中的必要项目；不机械要求每镜头塞满六项。
- 人物正在拿物时，记录哪只手、握持点、物体朝向；动作结束时给出可接下镜的手位与身体朝向。
- 说话可搭配轻微手势；嘴型服务真实台词，不让每个音节都引起全脸、眼镜或头部大幅变化。
- 连续动作保持起止状态、视线目标、行进方向与脚部落点。剪辑换景不自动重置动作或情绪。
- 只有剧情发生变化才改变情绪；同一段口播或连续镜头可以维持中性、专注或自信。
- 真正的前后对比可使用“焦虑→释然”等情绪弧线；不要为制造差异强行给每一镜换表情。
- 远景主要用轮廓、头角、肩胸、重心和步态表达，避免强迫视频模型在小脸上表现细碎表情。
- 文章配图模式可追求多图叙事变化，但“相邻图必须换情绪”不是视频规则。

## 生成后的检查

检查情绪是否有触发原因、脸与身体是否相容、动作是否能回到结束状态。
重点查看眨眼、转头、手触脸和遮挡恢复时的眼镜/五官稳定性，按 [质检清单](qa-checklist.md) 记录结果。
保持同一成年角色；不依靠放大眼球、缩短脸型、增加夸张哭泪或改变镜框制造情绪。
