# 视频工作流｜原版IP

1. 读取并查看原版身份照片、动漫角色卡、鞋板和按情节选择的表情/身体语言图。
2. 运行 prepare_original_pack.py，得到实际原始参考、中英文首帧与运动提示及连续性计划。
3. 使用真实图像工具生成场景首帧，和原版核对。角色卡是设计来源，不直接当视频首帧。
4. 使用 register_frame.py 登记真实首帧和来源，填写模板中的真实素材ID。
5. 用 prepare_video_pack.py 验证并导出，候选试用带 --allow-draft；拒绝清单在草案下也生效。
6. 按所选平台当前入口核验参数、上传场景帧、生成视频，再验收身份与动作连续性。

参考职责与视频提示是两个阶段。没有真实视频不声称完成视频测试，没有获认可的新图不写approved。详见 ../VIDEO_EXTENSION.md。
