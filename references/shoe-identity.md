# BIT东｜BIT / DONG 定制鞋识别规范（候选设计，不代表定稿）

## 识别对象与来源

本规范用于从来源鞋照提取可辨认的差异，并约束角色转面、鞋子近景与视频生成。`shoe_A_BIT`、`shoe_B_DONG` 是鞋款识别名，**不是角色解剖学左右脚**。必须核查 `assets/character-reference/shoes/` 的四张原始鞋照，不能仅凭屏幕左右推断穿在哪只脚。

| 属性 | shoe_A_BIT | shoe_B_DONG |
| --- | --- | --- |
| 高帮文字 | BIT | DONG |
| 鞋头红色主要线索 | D 形标记 | Z 形标记 |
| 鞋头可辨认的图案线索 | 圆头图案 | 带身体的人物图案 |
| 侧面要求 | 保留对应一侧的蓝色轮廓与内部纹样 | 重点复核外侧蓝色轮廓及其内侧小花纹 |

这张表只锁定上轮从来源图中复核出的**图案身份线索**，不能代替精确纹样、字形、线条位置或左右脚验收。若微小字样尚不清晰，应标为 `unverified` 而不是创造可读文字。

## 跨角度不可漂移项

- 两只鞋共用黑色高帮轮廓、黑色鞋带、米白中底、黑色外底、蓝色外侧装饰、紫色点缀和红色鞋头图案。
- 角色旋转时，鞋舌、鞋帮、鞋跟、鞋头与中底位置必须对应同一双鞋的结构；不能把 BIT 与 DONG 的标记互换。
- 角色左/右脚、鞋内外侧、屏幕左/右三个坐标系要分开记录。**不要使用水平镜像生成所谓另一侧视图**。
- 远景允许极细字样不可辨，近景特写不得把字母、鞋头图案、蓝色内部花纹、后跟黄橙细线擅自替换。
- 任何额外可见品牌文字、logo 或装饰均以实际参考图为准，不在缺失细节处猜想补画。

## DONG 鞋对侧图补齐标准

1. 从已选定的同套全身角色参考派生一张**真实改变观察角度**的对侧全身图，保持脸型、眼镜、粉色圆领卫衣、银链、炭黑长裤及左腕手表一致。
2. 另外制作 DONG 鞋外侧局部图，用鞋子原始照片作为**鞋细节参考**；禁止将照片的写实材质直接混入 2D 角色画风。
3. 逐项验收蓝色轮廓、轮廓内部小花纹、DONG 字样、红色 Z 形标记、人物图案、鞋跟线条。若实际生成省略小字，应在差异记录中标明。
4. 记录每张 PNG 的父图 `asset_id`、真实分辨率、SHA256、完整生成提示、视觉缺陷与 `candidate` 状态；不能拿裁切图插值冒充新母版。
5. 尚无用户明确批准时，不更新 `approved_master_set`，不把候选资产用于宣称已验收的正式视频包。

## 验收口径

结构/哈希检查、静态视觉检查、视频运行检查分别记录。没有拿到视频模型真实产出时，视频项目保持 `not_run`。鞋头红色微字、后跟细线及 DONG 蓝色内部花纹仍被简化时，局部精度不标 `pass`。该规则不要求所有远景都能清楚读出小字。
